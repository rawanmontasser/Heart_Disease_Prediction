# Heart Disease Prediction ❤️

A machine learning project for predicting the likelihood of heart disease using patient health-related features. The project includes data preprocessing, feature engineering, exploratory data analysis, visualization, and comparison of multiple machine learning models.

> **Note:** This project is developed for educational and research purposes. It is not intended to provide medical diagnosis or replace professional medical advice.

---

## 📌 Project Overview

Heart disease is one of the major health challenges worldwide. Machine learning can be used to analyze patient-related data and identify patterns that may be associated with heart disease.

In this project, a machine learning workflow was developed, starting from data preprocessing and feature engineering through model training and evaluation.

The project focuses on:

* Cleaning and preparing the data
* Exploring relationships between health-related features
* Engineering **12+ features**
* Visualizing important patterns
* Training multiple classification models
* Comparing model performance
* Evaluating predictive performance

---

## 🎯 Objectives

* Build a machine learning model for heart disease prediction.
* Perform data cleaning and preprocessing.
* Explore the dataset through statistical analysis and visualization.
* Create additional features to improve the modeling process.
* Train and compare different classification algorithms.
* Evaluate model performance using appropriate metrics.

## 🧹 Data Preprocessing

The dataset was prepared before training the machine learning models through data preprocessing and preparation steps.

The preprocessing workflow included:

* Data cleaning
* Preparing features for modeling
* Feature transformation

* Preparing the data for model training and evaluation

## ⚙️ Feature Engineering

More than **12 additional features** were engineered from the available data.

Feature engineering was used to create additional information from the original variables and provide the machine learning models with more useful features for prediction.

---

## 📊 Exploratory Data Analysis

Exploratory Data Analysis (EDA) was performed to better understand the dataset and investigate patterns related to heart disease.

The analysis included:

* Statistical analysis
* Feature distributions
* Relationships between variables
* Target distribution
* Data visualization

Visualization was used to explore patterns and relationships within the data before applying machine learning models.

---

## 🤖 Machine Learning Models

Several classification algorithms were trained and compared:

### Logistic Regression

Used as a baseline classification model for predicting the target class.

### Support Vector Machine (SVM)

A supervised learning algorithm used to classify observations into the target classes.

### Decision Tree

A tree-based classification algorithm that makes predictions through a series of feature-based decisions.

### Random Forest

An ensemble learning method that combines multiple decision trees for classification.

### XGBoost

A gradient boosting algorithm used for classification and model performance comparison.

---

## 📈 Results

The evaluated models achieved **up to approximately 80% accuracy**.

The models were compared to evaluate how different classification algorithms performed on the prepared dataset and engineered features.
